# kids-api

Backend API cho hệ thống KimThanh Kids (quản lý trường mầm non).

> 🚧 Chưa khởi tạo source. Thư mục này hiện chỉ có file README để Git theo dõi (Git không track thư mục rỗng).

## Dự kiến
- REST/GraphQL API phục vụ cho `kids-crm`, `kids-mobile-native`, `kids-mobile-web`
- Auth, quản lý lớp/học sinh, điểm danh, học phí, thông báo...

## Bắt đầu
Khi khởi tạo project (NestJS / Express / ...), nhớ thêm `.gitignore` để loại `node_modules`, `dist`, `.env`.
