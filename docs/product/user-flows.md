# Key User Flows

## Parent — view child's day

1. Open mobile app → biometric / token-rehydrate → ParentNavigator.
2. Home tab loads today's attendance status + most recent daily report.
3. Tap report → see photos/videos and teacher note.
4. Push notification (future) arrives when a new report is published.

## Teacher — morning routine

1. Open mobile app → TeacherNavigator.
2. "Attendance" tab → roster for today → mark each student PRESENT/ABSENT/LATE.
3. "Reports" tab → choose a student → write daily report → attach media → publish.

## Nurse — handle medicine request

1. Web dashboard → Health → pending list.
2. Click a request → review parent's instructions.
3. Approve or reject (writes back to the request, notifies parent).
4. Later: mark `ADMINISTERED` with a note.

## Finance — month-end

1. Web dashboard → Finance → invoices.
2. Filter by status `PENDING` + period.
3. Record payment when received; status transitions to `PAID`.

## Admin — onboard a new student

1. Web → Students → New.
2. Fill profile, assign classroom, link parent accounts.
3. Issue first tuition invoice for the current period.
