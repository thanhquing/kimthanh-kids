# User Roles

| Role | Surface | What they do |
|---|---|---|
| `SUPER_ADMIN` | Web | Cross-tenant ops, school onboarding. |
| `ADMIN` | Web | Tenant management, users, students, classes, announcements. |
| `FINANCE` | Web | Invoices, payments, reconciliation. |
| `NURSE` | Web | Approve medicine requests, log health records, incidents. |
| `TEACHER` | Mobile (+ Web) | Attendance, daily reports, media, classroom announcements. |
| `PARENT` | Mobile | View child's reports, attendance, invoices, request medicine. |

See `permissions-matrix.md` for the actual permission grid.
