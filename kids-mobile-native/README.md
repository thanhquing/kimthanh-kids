# kids-mobile-native

App di động native (iOS/Android) cho phụ huynh & giáo viên KimThanh Kids.

> 🚧 Chưa khởi tạo source. Thư mục này hiện chỉ có file README để Git theo dõi (Git không track thư mục rỗng).

## Dự kiến
- React Native / Expo (hoặc Flutter)
- Tính năng: theo dõi con, điểm danh, nhật ký bé, thông báo, học phí

## Bắt đầu
Khi khởi tạo project, nhớ thêm `.gitignore` để loại `node_modules`, build, `.expo`, `.env`.
